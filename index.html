Guide — Miia & Commandes Vocales

🤖 Miia — Votre assistante IA
💬 Comment l'ouvrir
Appuyez sur le bouton MIIA en bas à droite de l'écran d'accueil. Le chat s'ouvre.
🎙️ Lui parler depuis l'accueil
Appuyez sur le micro 🎤 de l'accueil et dites directement :
"Mia quels sont mes RDV cette semaine ?"
"Mia quel est mon CA ce mois ?"
"Mia j'ai combien de factures impayées ?"
Le chat s'ouvre et la réponse part automatiquement.
🎤 Lui parler dans le chat
Dans le chat, appuyez sur le micro à gauche du bouton envoyer — dictez votre question, elle part automatiquement.
🧠 Ce que Miia sait faire
📋 Réglementation — DPE, amiante, plomb, électricité, gaz, termites, durées de validité, obligations légales…
📊 Votre activité — RDV de la semaine, CA du mois, factures impayées, devis en attente, objectif mensuel…
🔊 Voix de Miia
Dans le chat, le bouton 🔊 / 🔇 en haut à droite active ou désactive la réponse vocale de Miia.
🎤 Commandes vocales — micro de l'accueil
Comment ça marche
Appuyez sur l'icône 🎤 de l'accueil, dites votre commande à voix haute. L'action se déclenche instantanément.
📂 Ouvrir un module
"ouvre le DPE" "ouvre l'amiante" "ouvre le plomb" "ouvre le gaz" "ouvre l'électricité" "ouvre les termites" "ouvre l'ERP" "ouvre le carrez"
🗂️ Naviguer dans l'app
"ouvre les missions" "ouvre les devis" "ouvre les factures" "ouvre les clients" "ouvre le profil" "ouvre les tarifs" "ouvre la checklist" "retour accueil"
📐 Commande spéciale
"ouvre la triangulation"
Ouvre directement le calculateur de triangulation dans le module Carrez.
💡 Conseil : La reconnaissance vocale fonctionne en français. Parlez naturellement, pas besoin de formulation exacte.
